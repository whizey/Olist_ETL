# Olist_ETL
End-to-end e-commerce analytics project using the Olist dataset. Built a full ETL pipeline with Apache Spark, PostgreSQL, and Power BI to process large-scale data and apply machine learning for seller segmentation.


* Built a full ETL pipeline using Apache Spark and PostgreSQL

* Cleaned, transformed, and engineered features from Olist e-commerce data

* Applied clustering algorithms for seller segmentation

* Designed an interactive Power BI dashboard for real-time insights

* Analyzed trends in sales, payments, and delivery performance
